# Quick Sort

Custom, independently developed C++ implementation of the Quick Sort algorithm. No AI-generated code.

## About

This repository contains a custom implementation of Quick Sort, developed independently as part of a personal collection of C++ programming projects.

**100% original, self-developed code. No AI assistance.**

## Algorithm

Quick Sort is a divide-and-conquer sorting algorithm that selects a pivot, partitions elements around it, and recursively sorts the resulting partitions.
